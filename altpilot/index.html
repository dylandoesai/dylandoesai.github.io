AltPilot

Unlimited AI alt text and image SEO for Shopify stores. One flat price. No per-image meter.

Every other bulk alt-text app charges you per image because it pays a cloud AI for each one. AltPilot runs its vision model on our own hardware, so we don't meter you: write alt text for 50 images or 50,000 for the same monthly price. Accessibility-correct, search-friendly, describes what's actually in the picture.

Try it in the browser

Paste any public product-image URL. The alt text is generated on our hardware while you wait (about 20 seconds).

—

Or from the command line

Send any public product image URL. You get alt text, search tags and a short description back. This is the live demo box, not a mock.

curl -X POST https://carmen-life-sys-priced.trycloudflare.com/alt \
  -H "Content-Type: application/json" \
  -d '{"image_url":"https://your-store.com/products/mug.jpg","product_title":"Ceramic Mug"}'
{"alt":"Four Egyptian figures harvesting wheat under a golden sun, one holding a scroll…",
 "tags":["ancient","egyptian","harvest","wheat","art"], "long_desc":"…", "cost_usd":0.0}

Also live on the same box

curl -X POST https://carmen-life-sys-priced.trycloudflare.com/translate -H "Content-Type: application/json" \
  -d '{"texts":["Hand-thrown ceramic mug, 12 oz, dishwasher safe."],"target_lang":"Spanish"}'
→ {"translations":["Taza de cerámica hecha a mano, 12 oz, lavavajillas seguro."],"words_in":8,"cost_usd":0.0}

Unlimited-words catalog translation, same flat price. Bulk jobs go through a durable queue (POST /jobs, GET /jobs/{id}) so a busy GPU delays work instead of failing it.
